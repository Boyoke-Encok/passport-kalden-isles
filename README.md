Draws the passport spread of the invented Republic of the Kalden Isles — a data page with portrait, bilingual fields and an ICAO machine-readable zone with real check digits, plus a visa/stamps page whose travel history agrees with the issue date.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, under 1 MiB). Needs Python 3.13 with Pillow and the DejaVu/Liberation system fonts. Deterministic: fixed geometry, no randomness, no network.
